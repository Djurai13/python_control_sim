# System Architecture

## High-Level Architecture

Simulation Engine
    ↓
Habitat Intelligence
    ↓
Detection & Removal
    ↓
Optimization Layer
    ↓
GIS Layer
    ↓
Dashboard Layer (Planned)

## Components

### Environment
Responsible for habitat suitability and spatial data.

### Python Agents
Models invasive species behavior.

### Hunter Teams
Models suppression operations.

### Optimizer
Performs hotspot analysis and hunter allocation.

### GIS Layer
Converts simulation coordinates into geographic coordinates.
